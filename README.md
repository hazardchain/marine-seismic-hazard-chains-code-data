# Code and data — Marine seismic hazard chains

[![DOI](https://zenodo.org/badge/1285695563.svg)](https://zenodo.org/badge/latestdoi/1285695563)

Reproducibility materials for *Network topology of marine seismic hazard chains and
contrasts with inland earthquake chains* (Shi, Hu, Zhang;
manuscript for *npj Natural Hazards*).

**Interactive network viewer (Figs 1 & 2):** <https://hazardchain.github.io/marine-seismic-hazard-chains-code-data/>
— click any node to trace its couplings; Chinese / English toggle. Source in [`docs/`](docs/).

## One document reproduces everything

**[`marine_hazard_chains_reproduction.Rmd`](marine_hazard_chains_reproduction.Rmd)** regenerates **every table and figure** in the
paper directly from the raw cascade tables in [`data/`](data/). Knit it
(RStudio → *Knit*, or `rmarkdown::render("marine_hazard_chains_reproduction.Rmd")`) to produce
`marine_hazard_chains_reproduction.html`, which contains, each next to the exact code that makes it:

- Marine network — **39 nodes / 152 edges**
- **Methods, Data and encoding** composition of the two records — event years, catalogue causes, the nine non-earthquake or erroneous catalogue events and a check that excluding them changes no marine conclusion
- **Table 1** node degrees and hubs · **Table 2** four-layer net flow (+42/+1/−16/−27) · **Table 3** 15-class marine (15 classes / 57 edges) vs inland (14 / 44), with the **Table 8** class mapping
- **Figure 1** marine in/out-degree network · **Figure 2** marine vs inland (15 classes)
- **Robustness and sampling sufficiency / Figure 3** — event-level cluster bootstrap, inclusion thresholds and five-fold out-of-sample edge coverage
- **Independent-event test / Figure 4, Tables 4–5** — three events (2004 Indian Ocean, 1960 Valdivia, 2018 Palu) overlaid on the network, with chance baselines for the coverage
- **Node removal / Table 6** — cascade reach (Eq. 6) and exhaustive search for the best sets of one to three nodes
- **Discussion** — two-step reach of the submarine earthquake, documentation depth of the marine events, and an equal-sample check of the marine–inland contrast (1000 draws of 58 of the 84 inland events)
- **`docs/graph-data.js`** — the interactive viewer's data, written from the *same* graph objects, so the web page never drifts from the figures

A pre-knitted **`marine_hazard_chains_reproduction.html`** is included, so the full reproduction can be
read without running R.

### Requirements & how to run

R (≥ 4.x) with `docxtractr`, `igraph`, `dplyr` (plus `rmarkdown`, `knitr` to knit):

```r
install.packages(c("docxtractr", "igraph", "dplyr", "rmarkdown", "knitr"))
rmarkdown::render("marine_hazard_chains_reproduction.Rmd")        # from the repository root
```

Paths are **relative** and use `file.path()`, which is correct on Windows, Linux
and macOS alike — no per-OS configuration is needed (R also accepts `/` on
Windows). The OS the run used is printed in the document's Session information.

## Changes in v1.2.1

- **Wording follows the corrected manuscript.** The paper now uses "hub" in one
  sense only (Table 1 footnote: in- and out-degree both >= 5 and within a factor
  of two; TS, CFL, CF and FI are hubs, TS and CF the main hubs). The code
  computes this definition (`hub_role()`), adds it to Table 1, and shows that the
  hubs are unchanged when the nine non-earthquake or erroneous events are
  excluded and when the three independent events are added. C2 now reads
  "highest out-degree SEQ, highest in-degree CF"; the novel couplings are counted
  against the core nodes SEQ, TS, CF and NF; the three independent events are
  "earthquake-generated" tsunamis (Palu 2018 is encoded as a coastal earthquake).
- **Reproduction document.** The subtitle carries the current title, and the
  section links of the overview table work (they printed as `@ref(...)` text).
- **Viewer.** The three-event overlay is labelled Figure 4, as in the paper.
- No number, table, figure file or `docs/graph-data.js` changed.

## Changes in v1.1.0 (revised manuscript)

*(Section, table and equation numbers below refer to the manuscript version of that release.)*

- **Inland comparison network.** The comparison network is restricted to inland
  earthquakes (epicentre on land, no tsunami in the chain). Ten events of the
  China tables with offshore epicentres or near-coast cascades are excluded in
  the code (`inland_excluded`), leaving 84 events, 500 chains and 14 classes
  (Table 4, Figure 2). The data files are unchanged.
- **Node removal (Sect. 3.6, Table 7)** replaces the greedy chain-breaking
  analysis. Pairs that start or end at a removed node are no longer counted as a
  reduction (Eq. 6), and the best sets are found by exhaustive search.
- **Five-fold edge coverage (Sect. 3.4).** Core links are now defined within the
  held-out fold, which removes a leak of the training events into the selection
  (core coverage ~98 % → ~96 %; Figure 3a).
- **Independent-event test (Sect. 3.5).** Adds the 1960 + 2004 coverage and
  chance baselines (random network; degree-preserving rewiring).
