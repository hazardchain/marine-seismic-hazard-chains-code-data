# Code and data — Marine seismic hazard chains (NHESS)

[![DOI](https://zenodo.org/badge/1285695563.svg)](https://zenodo.org/badge/latestdoi/1285695563)

Reproducibility materials for *Network Topology of Marine Seismic Hazard Chains:
Hubs, Layers and Contrasts with Inland Earthquake Chains* (Shi, Hu, Zhang;
submitted to *Natural Hazards and Earth System Sciences*).

**Interactive network viewer (Figs 1 & 2):** <https://hazardchain.github.io/NHESS-marine-seismic-hazard-chains-code-data/>
— click any node to trace its couplings; Chinese / English toggle. Source in [`docs/`](docs/).

## One document reproduces everything

**[`marine_hazard_chains_reproduction.Rmd`](marine_hazard_chains_reproduction.Rmd)** regenerates **every table and figure** in the
paper directly from the raw cascade tables in [`data/`](data/). Knit it
(RStudio → *Knit*, or `rmarkdown::render("marine_hazard_chains_reproduction.Rmd")`) to produce
`marine_hazard_chains_reproduction.html`, which contains, each next to the exact code that makes it:

- Marine network — **39 nodes / 152 edges**
- **Table 2** node degrees · **Table 3** four-layer net flow (+42/+1/−16/−27) · **Table 4** 15-class marine (15 classes / 57 edges) vs inland (14 / 44)
- **Figure 1** marine in/out-degree network · **Figure 2** marine vs inland (15 classes)
- **Sect. 3.4 / Figure 3** robustness — event-level cluster bootstrap, inclusion thresholds and five-fold out-of-sample edge coverage
- **Sect. 3.5 / Figure 4, Tables 5–6** independent-event test — three events (2004 Indian Ocean, 1960 Valdivia, 2018 Palu) overlaid on the network, with chance baselines for the coverage
- **Sect. 3.6 / Table 7** node removal — cascade reach (Eq. 6) and exhaustive search for the best sets of one to three nodes
- **`docs/graph-data.js`** — the interactive viewer's data, written from the *same* graph objects, so the web page never drifts from the figures

A pre-knitted **`marine_hazard_chains_reproduction.html`** is included, so the full reproduction can be
read without running R.

### Requirements & how to run

R (≥ 4.x) with `docxtractr`, `igraph`, `dplyr` (plus `rmarkdown`, `knitr` to knit):

```r
install.packages(c("docxtractr", "igraph", "dplyr", "rmarkdown", "knitr"))
rmarkdown::render("marine_hazard_chains_reproduction.Rmd")        # from the repository root
```

Paths are **relative** and use `file.path()`, which is correct on Windows, Linux
and macOS alike — no per-OS configuration is needed (R also accepts `/` on
Windows). The OS the run used is printed in the document's Session information.

## Changes in v1.1.0 (revised manuscript)

- **Inland comparison network.** The comparison network is restricted to inland
  earthquakes (epicentre on land, no tsunami in the chain). Ten events of the
  China tables with offshore epicentres or near-coast cascades are excluded in
  the code (`inland_excluded`), leaving 84 events, 500 chains and 14 classes
  (Table 4, Figure 2). The data files are unchanged.
- **Node removal (Sect. 3.6, Table 7)** replaces the greedy chain-breaking
  analysis. Pairs that start or end at a removed node are no longer counted as a
  reduction (Eq. 6), and the best sets are found by exhaustive search.
- **Five-fold edge coverage (Sect. 3.4).** Core links are now defined within the
  held-out fold, which removes a leak of the training events into the selection
  (core coverage ~98 % → ~96 %; Figure 3a).
- **Independent-event test (Sect. 3.5).** Adds the 1960 + 2004 coverage and
  chance baselines (random network; degree-preserving rewiring).
